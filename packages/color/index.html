工具函数 (@esdora/color) ​

欢迎来到 @esdora/color 的世界！这是 Dora Pocket 中用于处理颜色的“道具箱”之一。

本模块基于 culori 进行二次封装，提供了更友好的 API 和对 CSS 字符串的支持。同时也暴露出了 culori 的所有功能，你也可以直接使用 culori 的所有功能。
